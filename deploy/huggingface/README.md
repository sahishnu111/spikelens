# SpikeLens (Hugging Face Space)

This Space runs the Docker image from the SpikeLens GitHub repository.
Source, docs and benchmarks: see the GitHub repo.

Note: free Spaces have ephemeral disk, so streams created here are reset when the Space restarts.
Webhooks are disabled on the public demo (`SPIKELENS_ALLOW_WEBHOOKS=0`).
